## 📊 Data Transactions Dashboard

### Overview

This Power BI project visualizes transactional data to uncover key business insights, patterns, and performance metrics. It demonstrates my skills in data modeling, cleaning, and visual storytelling using Power BI.


### 🔍 Objectives

* Analyze total sales and revenue trends
* Identify top-performing categories and products
* Track customer and region-level performance
* Understand seasonal or monthly transaction patterns

---

### 💡 Key Features

* Interactive dashboard with filters by date, region, and product
* Visuals include:

  * Bar charts for category sales
  * Line charts for monthly revenue trends
  * Cards for total KPIs (sales, revenue, customer count)
  * Map view for regional sales distribution 


### 🛠️ Tools Used

* Power BI Desktop
* Data cleaning using Power Query
* DAX formulas for calculated columns and measures

### 📁 Dataset Info

> Note: The dataset is synthetic/mock (or anonymized real-world) and used for demo/learning purposes.

Fields include:

* Transaction Date
* Customer ID
* Product Category
* Sales Amount
* Region
* Quantity Sold

### 🚀 How to Use

1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Explore the dashboard or make modifications as needed.
4. (Optional) Connect your own dataset using the same structure.
